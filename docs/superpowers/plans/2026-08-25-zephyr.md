# Zephyr — Motion-Controlled 3D Flight Game · Implementation Plan

**Goal:** A playable open-world 3D flying game where the player's real body motions (webcam pose tracking) control a stylized bird/glider through a procedural skyworld of floating islands, rings, and clouds.

**Architecture:** Pure game logic modules (fully TDD'd, zero DOM/three imports) + thin adapter layers (renderer, input, audio, HUD) verified by production build + headless browser smoke test with real screenshots.

**Tech Stack:** Vite 7 (vanilla ES modules), Three.js, @mediapipe/tasks-vision (PoseLandmarker, lite model), Vitest, Playwright (smoke test only), WebAudio synth (no audio assets), gh CLI (repo publish).

**Global Constraints:**
- Windows host, no discrete GPU → integrated-Graphics budget: low-poly geometry, InstancedMesh, fog culling, pixelRatio ≤ 1.5, no postprocessing passes.
- All randomness through seeded PRNG (mulberry32) so worlds are reproducible and testable.
- Webcam optional at runtime: keyboard fallback must make the game fully playable without camera.
- No external runtime CDNs: MediaPipe wasm + model vendored into `public/`.
